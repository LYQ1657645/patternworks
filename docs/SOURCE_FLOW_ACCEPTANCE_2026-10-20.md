# Source flow and copy simplification — 2026-10-20

- Disconnected/restoring/connected states are separate. The source file panel is absent until connected; credentials form is absent once connected. A short entrance transition respects reduced motion.
- Disconnect S3 revokes all saved S3 connections owned by the current browser session, clears credential ciphertext and local file selection, and returns to the connection form. It preserves datasets, exports and history. It is S3 disconnection, not AWS account logout or full application-session deletion. Active S3 jobs must finish or be cancelled first; failed requests keep the connected screen for retry.
- Latest completed connection tasks restored from history no longer re-establish a disconnected connection. Only the active-connections endpoint restores live connections.
- File import progress, cancellation and result/history links sit beside Import. The global task strip and System status panel were removed. Task history remains available.
- Removed duplicate connected/credential notes, file metadata/count footnotes, repeated dataset timestamps and technical Spark/job details. Short action guidance uses a consistent, stronger style. Operational results, errors, retention/dependency warnings and provider-data consent remain available.
- Local tests: 332 backend tests passed, 12 Spark tests excluded; 35 frontend tests passed; TypeScript/Vite build passed. AWS: 12 targeted disconnection/session tests passed before deployment. The unchanged Spark pipeline was not benchmarked again for this UI change.
- Public Safari verified connected-only file list, progress beside Import, disconnect returning to the form, refresh staying disconnected, and retained imported dataset/download controls. Transform screen reviewed visually. Narrow local browser viewport measured 300px and document scrollWidth 300px after navigation spacing correction. Dedicated automated design inspector was not run; browser screenshots were inspected directly.
- Existing server updated in place, with source/image rollback copies under `/home/ubuntu/source-flow-20261020-backup` and `*:before-source-flow`. No GitHub publication.
